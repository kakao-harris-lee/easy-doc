## 2. 통지 방법 (부분 확인)

- **전화만 확인됨**: PDF·웹 저작권 고지문 모두 "법제정보담당관(044-200-6900)으로 통지하여 주시기 바랍니다"라고만 되어 있고, 통지 방법을 전화로 한정하는지 다른 수단(공문, 이메일)도 허용하는지는 명시돼 있지 않습니다.
- 공문·이메일·온라인 양식의 존재 여부: **확인 불가**.
- **권장**: 사용자가 044-200-6900으로 전화해 담당자에게 이메일 주소나 공문 접수 방법을 먼저 물어보고, 그 경로로 아래 3번 내용을 전달하는 방식이 가장 확실합니다. (전화 문의는 사용자가 직접 진행 — 에이전트는 하지 않았습니다.)

## 3. 통지에 담을 내용 (초안 — 요구 항목이 별도로 정해져 있지 않아, 상식적으로 필요할 내용으로 구성)

> 아래는 "이런 내용이 필요할 것"이라는 초안이며, 법제처가 정한 필수 양식이 있는지는 **확인 불가**입니다. 통지 시 실제 요구 항목을 담당자에게 먼저 확인하는 것을 권합니다.

- **서비스 개요**: 지적·발달장애인을 위한 공공/복지 문서 쉬운 글 변환 서비스(easy-doc)에서 사용할 RAG(검색 증강 생성) 사전 구축 프로젝트
- **이용 목적**: 복지 분야 공공문서의 어려운 용어를 지적·발달장애인이 이해하기 쉬운 표현으로 변환하는 서비스에서, 용어의 정확한 법적 정의와 오치환(예: 과태료↔벌금 같은 혼동) 방지 근거자료로 활용
- **이용 범위 (현재)**: "찾기쉬운 생활법령정보" 중 복지 카테고리(csmAstSeq=13) 하위 "기초생활보장" 중분류(csmSeq=1533) 1건의 PDF(52쪽)에서 용어 정의문을 추출해, 복지 용어 시드 데이터 68건 작성에 참조함
- **이용 범위 (향후 확대 가능성)**: 복지 카테고리 35개 중분류(기초생활보장, 긴급복지지원, 노인복지, 장애인 생활안정 등)로 확대 검토 중. 확정된 범위는 아니며 easy-doc의 코퍼스 분석 결과에 따라 결정 예정
- **영리 목적 여부**: (사용자가 채워야 할 항목 — 서비스가 상업적 B2G 납품을 목표로 한다면 그렇다고 명시 필요)
- **출처 표시 방식**: 산출물의 `sources` 테이블에 기관명(법제처)·자료명("찾기쉬운 생활법령정보")·URL(easylaw.go.kr)·공공누리 유형(제1유형, 아래 5번 참조)을 기록하고, 서비스 산출물(용어 설명 화면 등)에도 출처를 표시할 예정

## 4. 사전 통지인가 사후 통지인가 (확인 불가 — 원문 재인용)

원문: "단순 인용이 아닌 영리목적의 이용이거나 자료의 상당 부분을 이용하는 경우에는 해당 사항을 법제처 법제정보담당관(044-200-6900)으로 통지하여 주시기 바랍니다."

- 이 문장은 **"이용하는 경우"를 조건으로 "통지"를 요청**할 뿐, 통지를 이용 **이전**에 해야 하는지 **이후**(사용자가 검토 중인 방향)에 해도 되는지는 **명시돼 있지 않습니다.** 사전/사후 어느 쪽으로도 읽을 수 있는 문장이며, 조사로는 확정하지 못했습니다.
- 참고로 공공누리 제1유형 자체(아래 5번)는 통상 "통지" 의무를 요구하지 않고 "출처표시"만 요구합니다. 이 "통지" 조항은 easylaw.go.kr/법제처가 저작권 고지문에 **별도로 추가한 안내 문구**로 보이며, 법적 강제력의 수준(권고 vs 의무)도 원문만으로는 판단하기 어렵습니다.

## 5. 공공누리 유형 번호 (확인됨)

**제1유형(출처표시)** 입니다.

근거: 공공데이터포털에 등록된 "법제처_생활법령정보 조회 서비스"(오픈API) 페이지에 다음과 같이 명시되어 있습니다.
> `https://www.data.go.kr/data/15000215/openapi.do` → "**공공저작물 : 출처표시 (제 1유형)**"

**단서**: 이 표기는 data.go.kr에 등록된 "생활법령정보 조회 서비스"(API/데이터셋)에 대한 라이선스 표기입니다. easylaw.go.kr 웹사이트나 PDF 문서 자체에 공공누리 마크(로고)가 별도로 부착되어 있는 것을 직접 확인하지는 못했습니다. 다만 (a) 같은 법제처가 소관하는 동일한 콘텐츠("생활법령정보")라는 점, (b) 앞서 확인한 easylaw.go.kr 자체 저작권정책 문구("출처표시 + 영리목적 포함 자유이용 보장")가 공공누리 제1유형의 조건과 사실상 일치한다는 점에서, **제1유형으로 보는 것이 합리적**이라고 판단합니다. 다만 이것이 "동일한 라이선스"라는 완전한 증명은 아니므로, 통지 시 담당자에게 이 점(웹/PDF 콘텐츠도 동일하게 제1유형인지)을 함께 확인해 두면 더 안전합니다.

3. 통지 필수 기재 항목 양식 — 못 찾음.
4. 사전/사후 통지 여부 — 원문에 명시 없음.
5. easylaw.go.kr 웹/PDF 콘텐츠 자체의 공공누리 유형 표시(로고) — 직접 확인 못함. data.go.kr 등록 정보(제1유형)로 간접 추정.

이 5가지는 **044-200-6900 통화 시 사용자가 직접 확인하는 것이 가장 확실**합니다.
