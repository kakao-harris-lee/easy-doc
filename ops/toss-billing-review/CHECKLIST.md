# 결제경로 최종 캡처 체크리스트 (운영자용)

토스페이먼츠 결제 계약 심사에 내는 그림은 **운영자 PC에서 직접 찍은 전체 화면 캡처**
여야 한다. `capture.mjs`가 만든 `out/*.png`는 "무엇을 어떤 상태로 찍어야 하는지"를
보여주는 초안일 뿐이고, 제출본은 아래대로 다시 찍어 `final/`에 넣는다.

## 0. 찍기 전에 확인할 것

- **심사 계정에 진행 중인 구독이 없어야 한다.** 이미 Start 구독이 살아 있으면
  정기결제 버튼이 비활성화되어 ⑤·⑥을 찍을 수 없다. 구독이 있으면 먼저 갱신을
  중단하고 이용 기간이 끝난 계정을 쓰거나, 심사 전용 계정을 새로 만든다.
- **결제 동의 체크박스를 켜야 버튼이 켜진다.** ⑤-2를 건너뛰면 ⑥으로 넘어가지 않는다.
- **테스트 키라 실제 청구는 일어나지 않는다.** 그래도 **실제 카드 번호는 넣지 않는다.**
  ⑥은 카드 등록창이 "열린 화면"까지가 제출 범위다. 카드 정보를 입력하거나 등록을
  완료할 필요가 없다.
- 캡처 도구: **Win + PrtScn**(전체 화면이 `사진\스크린샷`에 PNG로 저장된다).
  영역 캡처(Win+Shift+S)는 쓰지 않는다 — 주소창과 시계가 잘린다.

## 1. 모든 캡처에 공통으로 보여야 하는 것

| 항목 | 기준 |
| --- | --- |
| 주소창 | `easydoc.kr` 도메인이 **잘리지 않고** 읽혀야 한다. 전체 화면(F11) 모드는 쓰지 않는다. |
| 북마크 바 | **숨긴다** (Ctrl+Shift+B). 개인 북마크가 심사 자료에 남지 않게 한다. |
| 작업표시줄 | **시계가 보이도록** 작업표시줄을 숨기지 않는다. 날짜·시각이 순서대로 올라가는 것이 자료의 신뢰 근거다. |
| 캡처 범위 | **화면 전체**. 브라우저 창만 잘라내지 않는다. |
| 창 크기 | 브라우저를 최대화한다. 1600×900 이상 해상도를 권장한다. |
| 기타 | 다른 탭 제목, 알림 팝업, 개인 정보가 보이는 창을 미리 닫는다. |

## 3. 순서와 시각 흐름

1. **한 번에 이어서 찍는다.** ② → ③ → ④-1 → ④-2 → ⑤-1 → ⑤-2 → ⑥ 순서로,
   중간에 자리를 뜨지 말고 연속으로 진행한다.
2. 작업표시줄 시계가 **순서대로 올라가는** 것이 조작하지 않았다는 근거가 된다.
   나중에 한 장만 다시 찍어 끼워 넣으면 시각이 뒤섞여 보이므로, 다시 찍어야 하면
   **그 장부터 끝까지 다시** 찍는다.
3. ④-1은 **로그아웃 상태**가 전제다. 시크릿 창으로 시작하면 ②~④를 시크릿 창에서,
   ⑤~⑥을 그 창에서 로그인한 뒤 이어서 찍으면 흐름이 자연스럽다.
4. 다 찍은 뒤 `final/`에 위 파일 이름 그대로 넣고 PPT를 다시 만든다.

```bash
cd ops/toss-billing-review
.venv/bin/python build_pptx.py
```

회색 「최종 캡처 필요」 상자가 하나도 남지 않으면 교체가 끝난 것이다.

## 4. 하지 말 것

- 그림 위에 **주소창·시계·작업표시줄을 합성하거나 그려 넣지 않는다.** 카드사는 캡처의
  시각 정보로 조작을 확인한다. 합성이 발견되면 서류 전체의 신뢰가 깨진다.
- 캡처를 잘라내 주소창·시계를 **지우지 않는다.**
- **실제 카드 번호·CVC·비밀번호**를 화면에 남기지 않는다.
- 다른 고객 정보나 다른 서비스 창이 보이는 상태로 찍지 않는다.
