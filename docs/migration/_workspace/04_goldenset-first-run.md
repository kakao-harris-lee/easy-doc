## 왜 기준선으로 굳히지 않았나

**두 조건이 비어 있다.**

1. **직전 저장 실행(2026-08-08)의 36/56 = 64.3% 보다 9%p 낮다.** 같은 코퍼스인데
   떨어졌고 **원인을 가리지 않았다.** 낮은 값을 하한선으로 삼으면 그 하락이 정상이
   되고, 다음 실행은 저하된 값과 비교해 통과한다.
2. **무엇으로 쟀는지 모른다.** `context.model` 이 `null` 로 기록됐다 —
   `settings.llm_model` 이 미설정이라 실행이 자기가 쓴 모델을 기록하지 못했다.
   `.env` 의 `LLM_EFFORT` 차이일 수도 있고 실제 품질 하락일 수도 있는데 **구분할
   근거가 파일에 없다.**

그래서 `tests/golden/baseline.json` 을 저장소에서 내렸다. 저장소에 있는 순간
**활성화**되기 때문이다 — 파일이 있으면 다음 실행이 그것과 비교한다.

## 기준선을 다시 기록하는 조건

3. 그 뒤 같은 조건으로 다시 기록하고 diff 를 리뷰에 올린다.
