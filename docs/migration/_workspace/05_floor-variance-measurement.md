# 하한선 실행 간 변동 실측 (2026-08-13) — 허용 폭의 유일한 근거

**이 문서가 정책 수치의 근거다.** 허용 폭을 고치려는 사람은 여기 표본을 먼저 읽어라.
숫자만 옮겨 적고 근거를 두고 오면 다음 사람이 마음대로 올린다.

## 왜 쟀나

하한선 정책은 2026-08-12 사용자 결정으로 **"직전 기록 대비 하락 0"** 이었다.
그때는 **실행 간 변동 폭을 몰랐다** — 알 방법이 없었다. `baseline.json` 이 없어
비교 자체가 성립한 적이 없었기 때문이다.

2026-08-13 첫 정식 기록(`37331bd`, 33/56·미측정 0)이 서면서 처음으로 판정이 돌았고,
**두 번째 실행이 즉시 차단**됐다(33→31). 코드는 한 줄도 안 바뀐 상태였다. 그래서
"이것이 거짓 차단인가 진짜 신호인가"를 가르려고 표본을 늘렸다.

## 조건 — 다섯 실행이 무엇이 같았나

```
GOLDEN_PROVIDER=anthropic  LLM_MODEL=claude-sonnet-5  LLM_EFFORT=low
uv run pytest tests/golden -m llm
```

같은 커밋 · 같은 코퍼스(`corpus_sha256 eca83d43…`) · 같은 판정 기준
(`criteria_sha256 4f61553d…`) · 같은 producer(`anthropic/claude-sonnet-5/effort=low`).
**미측정 0** — 다섯 실행 모두 56건이 전부 모델에 닿았고 judge 커버리지 56/56.

`비교 불가` 는 한 번도 안 났다. 즉 지문 세 축이 독립 실행 다섯 번에 걸쳐 맞물렸다 —
그 자체가 producer 축(2026-08-13 신설)이 흔들리지 않는다는 실측이다.

**차이는 LLM 비결정성뿐이다.**

## 읽어낸 것 셋

**⑴ 부분이 전체보다 더 흔들린다.** 폭이 전체 2 < 합성 3 < 실수집 4다. 두 하위 축이
반대로 움직여 상쇄되기 때문이다. **run 4 가 그 실물이다** — 합성 14(최저)·실수집
19(최고)인데 전체는 33으로 기준선과 **정확히 같다.** 그런데도 합성 하나 때문에
차단됐다. 하위 축을 차단축으로 두면 전체가 멀쩡해도 걸린다.

**⑵ 관측 변동이 이항 잡음보다 작다.** 세 축 모두 실측 표준편차 < 이항 sd다
(0.89<3.70, 1.10<1.82, 1.67<2.99). 즉 이 변동은 **품질 신호가 아니라 표본 잡음**이며,
오히려 예상보다 조용하다. 잡음을 회귀로 읽는 게이트는 게이트가 아니라 알람 소음이다.

**⑶ judge 는 규칙 통과율과 같은 방향으로 움직이지 않았다.** 전체가 최저였던 run 2 의
judge 충실성이 4.71 로 오히려 상위였다. 두 축이 서로를 검증해 주지 않는다 —
judge 를 비차단으로 둔 2026-08-12 결정과 정합한다.

## 정책 변경 (사용자 결정, 2026-08-13)

**A. 차단축은 `overall` 하나다.** `synthetic`·`collected` 는 기록·경고만 한다.
**B. 실측 폭 2 를 허용한다.** `overall` 이 기준선 −2 **미만**일 때만 차단한다
(기준선 33 → **31 미만에서 차단**).

## 이 정책이 못 잡는 것 — 오독 금지

게이트를 **약화시킨 변경**이다. 무엇을 포기했는지 적어 둔다.

- **`overall` 이 2건 이하로 진짜 회귀해도 통과한다.** 잡음과 구분할 방법이 없어
  치른 대가다
- **하위 축에만 갇힌 회귀는 차단하지 않는다.** 합성이 무너져도 실수집이 그만큼
  오르면 통과한다 — run 4 가 정확히 그 형태였다(다만 그때는 회귀가 아니라 잡음이었다)
- **허용 폭 2 는 표본 5회의 관측 폭이지 분포 추정이 아니다.** n=5 로 분산을 추정하면
  그것이 곧 "범위가 근거를 넘는" 짓이다. 표본이 쌓이면 다시 정한다
- 이 폭은 **이 코퍼스·이 producer 에 한정**된다. 벤더나 모델을 바꾸면 지문이 달라져
  비교 불가가 되고, 그때 폭도 다시 재야 한다
