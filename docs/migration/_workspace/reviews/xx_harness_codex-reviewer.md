```
잡은 것은 라쳇도 바닥도 아니라
`test_리포트에_나온_클래스는_전부_선언에_있다` 하나였고,
```

**교훈 (계획서 명시):**
```
남는 교훈(규칙 7 에 반영): 두 장치가 중복인지는 「무엇을 막는다고 적혀 있는가」가 아니라
```
