### R-1 · R-2 — 전체 게이트 표시 파일의 자기 무장은 **CI 에서 도달 0** 이다

`6e6fbbf` 와 `.github/parity-full-gate.txt` 는 이렇게 선언한다.

> *"도달하는 **순간**(선언이 정본 전부를 덮는 실행) 비교기가 '하한을 고정하라'며 막으므로, 만들어 두는 것을 잊을 수 없다."*
> *"하는 일은 강등을 불가능하게 만드는 것이 아니라 **조용할 수 없게** 만드는 것이다."*

**두 문장 모두 CI 경로에서 성립하지 않는다.**

```python
def full_gate_floor_problems(selected: list[str], scoped: bool) -> list[str]:
    if scoped or not selected:
        return []
```
`selected` 는 `--only-domain` 이다. **CI 는 `declared_count == canonical_count` 일 때 `--only-domain` 을 주지 않는다**(`ci.yml:433-447`). 즉 8/8 인 지금 CI 가 도는 경로에서 이 함수는 **첫 줄에서 돌아온다.**

실측 3종:

| 대조 | 상태 | 결과 |
|---|---|---|
| **NC-1** | 표시 파일 삭제 + `--only-domain` 없음 (= **CI 의 실제 8/8 경로**) | **exit 0 · 경고 한 줄 없음** |
| **NC-2** | 표시 파일 삭제 + 부분(7/8) | **exit 3** → `ci.yml:460-466` 이 **exit 0** 으로 매핑 = **사면 부활** |
| **NC-3** | 표시 파일 존재 + 부분(7/8) | **exit 1** · `전체 게이트에서 내려왔다: export` ✔ |

**원 #3(도메인 추가 커밋 **한 번**으로 강등)은 닫혔다** — NC-3 이 그 증거다. 잔여는 **2커밋 경로**다: ⑴ 표시 파일을 지운다(CI 침묵, NC-1) → ⑵ 나중에 도메인을 더한다(CI 초록, NC-2). 어느 diff 도 "게이트를 내렸다"를 **강등과 함께** 보여 주지 않는다.
