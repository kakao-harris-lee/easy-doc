# R2 평가 증거

2026-09-21 승인된 평가에서 받은 20개 후보와 실행 조건이다. `manifest.json`은 각 파일의 SHA-256, 호출 수, 토큰, 보수적 비용 예약액과 예상 비용을 기록한다. 예상 비용은 확정 청구액이 아니다.

자료 출처·문서 ID·이용조건·고정 원문 및 기존 변환 해시는 [R0 기준선](../2026-09-18-easy-read-r0-baseline.md)에 있다. `023` 원문은 제주특별자치도 공고 제2026-2658호이며 공공누리 제1유형 출처 표시 조건을 유지한다. 그 밖의 원문도 같은 기준선의 기관·서비스 식별자를 따른다.

`valid` 결과는 production parser로 직렬화한 후보이고, `invalid` 결과는 진단을 위해 보존한 모델 응답이다. 사용자에게 제공 가능한 결과라고 간주하지 않는다. 파일별 판정과 지연은 [평가 보고서](../2026-09-21-r2-model-evaluation.md)에 있다.

보류 표본 `089,097,074,101`은 이번 평가에 사용했다. 이 결과를 보고 프롬프트나 생성 동작을 수정한다면 후속 독립 평가에는 새 보류 표본을 확보한다. 이 파일들을 승인된 golden 답안으로 편입하지 않는다.
