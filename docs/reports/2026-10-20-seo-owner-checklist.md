# 검색 노출 확인 — 운영자 실행 순서

확인 기준일: 2026-10-20. 이 문서는 등록 여부와 실제 색인·노출 결과를 구분한다.

## 1. 공개 인터넷에서 접속 확인

휴대폰 Wi-Fi를 끄고 아래 주소를 연다.

- `https://easydoc.kr/`
- `https://easydoc.kr/robots.txt`
- `https://easydoc.kr/sitemap.xml`

2026-10-20 작업 호스트의 내부 경로는 200이지만, 공인 주소 직접 접속은 시간 초과다. Google과 Cloudflare 공개 DNS는 모두 `219.254.58.102`를 반환했다. 내부망의 NAT 재접속 제한일 수도 있으므로 이 결과만으로 전체 외부 장애라고 단정하지 않는다.

모바일 데이터에서도 실패하면 공인 IP, 공유기의 80/443 포트 전달, Windows/WSL 전달 경로와 방화벽을 확인한다. 정상 연결이 입증될 때까지 SEO 태그 변경을 접속 문제의 해결책으로 취급하지 않는다. 기존 www 인증서 정책 변경은 이번 작업에서 하지 않는다.

## 2. 구글 서치콘솔

기존 기록상 2026-10-02 도메인 소유 확인과 색인 요청을 완료했다. 다시 속성을 만들 필요는 없다.

1. `easydoc.kr` 속성에서 `https://easydoc.kr/`를 URL 검사한다.
2. 아래 항목을 기록한다.
   - 현재 색인 여부, 미색인이면 표시된 사유
   - 마지막 크롤링 날짜와 페이지 가져오기 결과
   - 크롤링 허용 여부와 색인 생성 허용 여부
   - Google이 선택한 표준 URL
3. **실제 URL 테스트**를 실행한다. HTML에서 서비스 제목과 본문이 보이는지 확인한다.
4. 변경 배포 후 `/guide`도 검사하고, 사이트맵에 두 URL이 있는지 확인한다.
5. 접속·색인 허용 문제가 없고 내용이 갱신됐다면 색인 생성을 요청한다. 같은 URL을 매일 반복 요청하지 않는다.

현재 서치콘솔의 계정 내 결과는 작업 에이전트가 확인하지 못했다. 운영자가 상태 문구와 날짜를 전달해야 실제 성공 여부를 판단할 수 있다.

## 3. 네이버 서치어드바이저

기존 사이트 `https://easydoc.kr`에서 확인한다.

1. 소유 확인이 유효한지 확인한다. 확인용 HTML 파일은 서버에 존재한다.
2. 사이트 간단 체크 / 웹페이지 최적화에서 홈페이지의 응답과 검색 허용 여부를 확인한다.
3. robots.txt 수집, 사이트맵 제출 상태, 홈페이지 수집 결과를 확인한다.
4. 변경 배포 후 사이트맵과 `/guide` 수집을 요청한다.
5. 보고서의 수집·색인·검색 노출 수치를 기록한다.

수집 성공과 검색 노출 성공은 다르다.

## 4. 사업자 정보와 결제 안내

- 사용자가 확인한 신고번호 **제 2026-제주아라-0119 호**를 `frontend/src/config/company.ts`에 반영했다. 기존 푸터가 표시한다.
- 공개 이용약관의 사업자 정보와 유료 출시 초안의 신고번호도 맞췄다. 공개 약관은 사업자 정보만 갱신하며 결제 동의 버전·환불 조건은 바꾸지 않는다.
- 원래 작업 트리에 전화번호 변경이 있으므로 배포 준비 시 보존해야 한다.
- 신고 완료가 실결제 활성화를 의미하지 않는다. 이번 작업은 결제 환경·활성화 플래그·요금 정책을 바꾸지 않는다.
- 가이드 FAQ의 무조건적인 “실제 돈은 청구되지 않습니다”를 제거하고 테스트 결제로 표시된 경우에만 해당한다고 명확히 한다.

## 5. 검색 유입과 마케팅 효과

최초 기준값을 적고 주 1회 같은 조건으로 비교한다.

| 측정 | 기록할 값 |
| --- | --- |
| 검색 상태 | 홈페이지·가이드 각각의 색인 여부와 최근 수집일 |
| 구글 실적 | 최근 7일 노출·클릭·검색어·방문 페이지 |
| 네이버 실적 | 제공되는 수집·색인·노출·클릭 지표 |
| 체험 | 기존 운영 화면에서 확인 가능한 가입·인증·첫 변환 수 |
| 유료 전환 | 실제 결제 활성화와 승인 확인 후에만 측정 |

새 추적기를 설치하지 않았으므로 검색 방문자별 가입·결제 기여도를 현재 측정할 수 있다고 주장하지 않는다.

다음 콘텐츠 후보는 가정통신문, 고객 안내문, 제품 설명의 전후 비교다. 공개 가능한 원문과 담당자 허락을 확보하고, AI 출력 여부·사람 수정 여부를 구분한다. 실제 품질 비교나 독자 평가 없이 이해도 향상·시간 절감·경쟁 제품 대비 우월 수치를 쓰지 않는다.
