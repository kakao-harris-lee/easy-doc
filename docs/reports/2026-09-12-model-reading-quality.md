# 모델·추론 강도와 쉬운 글 품질 실측

유료 측정 완료: 공개 문서 5건, 변환 시도 18회, 최종 결과 17개, LLM 호출 52회. **이번 예상 비용 US$4.100860, 이전 측정 포함 US$5.565252 / 승인 상한 US$20.** 이번 예약액과 이전 실제 토큰 비용의 합계도 US$19.423988이다.

이번 표본에서는 **GPT-6 Astra / medium**이 의미 보존과 개념 설명에 가장 적합했다. 문장만 나누던 결과에서 벗어나 소득·가족 관계·필요 서류·조건의 관계를 설명하는 개선을 확인했다. 다만 원문 오타의 뜻을 확인하지 못한 보류 표본이 남아 있어, 모든 문서에서 고학년 독해 목표를 달성했다고 주장하지 않는다.

**비용 요구 반영:** 이 품질 비교를 운영 기본 모델 선정으로 확정하지 않는다. 동일 phase2의 제품 비용은 Astra가 Sol의 2.10배였고, Astra 비용의 51.2%는 보정에서 발생했다. 품질 조건을 충족하는 구성 중 최저 비용을 선택하도록 [운영 비용 재검토와 후속 계획](2026-09-12-model-cost-review.md)을 추가했다. 이번 비용 검토에서는 추가 유료 호출이나 로컬 설정 변경을 하지 않았다.

## 무엇을 고쳤는가

단순히 모델에 “초등학교 고학년 수준”을 요청하는 것만으로는 부족했다. OpenAI 어댑터는 기존 `EASYDOC_LLM_EFFORT` 값을 요청에 보내지 않았고, 변환 예문은 관련 문장도 한 줄씩 나누는 형태였다. 보정 지침에는 공식 이름 보존 지시가 빠져 있었다. 사실을 되살린 보정문도 문장 길이 위반이 늘면 기각됐다.

- OpenAI Responses 요청에 `reasoning.effort`를 연결했다. 미설정 요청은 기존 형태를 유지한다. GPT-5.6/6에서는 캐시 경계 없는 explicit 모드로 자동 캐시 쓰기 과금을 피한다. `store=false`를 유지한다.
- 독해 수준을 5~6학년으로 고정하고, 관련 문장을 문단으로 연결하는 예문을 넣었다. 핵심 개념은 역할·활동·비교 대상을 설명하고 나서 사용하도록 했다.
- 기관명·법령명·서류명·첨부파일명과 원문의 각 날짜를 보존하도록 변환·보정을 맞췄다. 원문에 없는 법령 이름이나 자격을 추측해서 추가하지 않도록 했다.
- 한 줄에 제시된 첨부파일 이름을 사실 검사에 포함했다. 공백이 있는 날짜, `%/퍼센트/프로`, 단위 없는 표 숫자를 원 단위 금액으로 풀어 쓴 경우를 보강했다. 숫자 뒤에 명시된 다른 단위가 있으면 금액 동치로 인정하지 않는다.
- 새 사실 누락이 없으면서 기존 누락을 복원한 보정은 길이 지적이 늘어도 채택한다. 사실 누락이 그대로면 기존 문체 기준을 적용한다. 최대 1회 보정은 유지한다.
- judge는 정확히 `yes`인 응답만 통과시키며 절단된 응답은 실패시킨다. 원문의 연도 불일치를 유지한 것을 잘못이라고 평가하지 않도록 기준을 고쳤다. judge에도 측정에서 지정한 출력 한도를 전달한다.

숫자·이름 검사는 규칙 기반의 일부 보존 검사다. 일반 기관명을 모두 추출하거나, 모든 조건의 AND/OR 관계 및 수치의 적용 대상을 보장하지 않는다.

## 연구를 적용한 방식

쉬운 정도와 의미 보존을 따로 본다. 하나의 종합 점수는 둘 사이의 손해를 숨길 수 있다. [Cripwell 외, READI 2024](https://aclanthology.org/2024.readi-1.1/)

원문에 관한 질문에 변환문만 읽고 답할 수 있는지 직접 대조한다. 독해 질문을 활용한 연구에서도 자동 단순화의 정보 누락이 확인됐다. 이번 한국어 표본에 그 논문의 수치를 그대로 적용하지 않는다. [Agrawal·Carpuat, TACL 2024](https://aclanthology.org/2024.tacl-1.24/)

judge의 합격률을 독자 이해율로 보지 않는다. 명확한 기준과 경계 사례를 주고, 출력 본문을 별도로 대조한다. [OpenAI 평가 지침](https://developers.openai.com/api/docs/guides/evaluation-best-practices)

Sonnet 5의 `low`와 `high`는 실제로 다른 비용·출력 길이·절단 결과를 냈다. 강도를 높이면 언제나 좋은 문서가 나온다고 가정하지 않는다. [Anthropic Sonnet 5 지침](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-sonnet-5)

## 표본과 실행 조건

사용자는 OpenAI 키 사용과 모델·effort 비교를 포함해 US$20까지 승인했다. 이전 측정 US$1.464392를 포함해도 상한 안에 있도록, 새 실행의 보수적 예약 합계를 US$18.535608 이하로 제한한다. 재시도도 호출 전에 예약하고 예약액을 반환하지 않는다. 토큰 응답에 따른 예상 사용액은 별도로 집계한다.

기존 Kotlin `GoldenCorpusLlmEvaluationTest`만 사용했다. Python 구현이나 새 평가 하네스는 없다. 임시 실행 도구는 환경 설정·순차 Gradle 실행·비용 예약 합산을 담당한다.

## 사전과 다른 해결 방법에 대한 판단

현재 RAG는 검수된 참고 용어·정의·주의와 예문을 프롬프트에 넣는 방식이다. 법령 원문을 조회해서 누락된 자격 기준을 채우는 검색 기능은 아니다. 지난 측정에서 사전을 뺀 조건도 날짜·서류명·개념 설명 문제를 해결하지 못했다. [이전 사전 포함/제외 실측](2026-09-11-reading-level-measurement.md)

이번 비교는 사전 컨텍스트를 동일하게 유지했다. 따라서 Astra의 개선을 사전 자체의 효과라고 주장하지 않는다. 사전을 단순 치환 목록으로 강제하거나, 검수되지 않은 정의·법령을 더 많이 검색해 넣는 방식은 채택하지 않았다. 공식 이름 보존과 개념 설명을 분리하고, 출력 본문을 독해 질문으로 대조하는 절차를 적용했다.

원문에 없는 구체적인 법적 자격을 설명하려면 별도의 검증된 근거 자료가 필요하다. 이번 작업에서는 원문을 추정으로 고쳐 쓰거나 실시간 법령 검색 기능을 새로 구현하지 않았다.

## 최종 추가 검증

phase2의 미달 사례를 보고, 필요한 서류의 역할과 숫자가 들어간 용어의 범위를 더 구체적으로 설명하는 일반 지침을 추가했다. 특정 문서의 정답 문구를 예문으로 넣지 않았다. phase3는 부모상담 087 재실행과 보류 문서 088·090 각 1회다. 프롬프트가 달라졌으므로 phase2와 동일 조건의 반복 성공률로 합산하지 않는다.

| 문서 | 결과 | 직접 대조 |
|---|---|---|
| 087 부모상담 | judge 통과 | 1촌·2촌을 부모/자녀·형제자매·조부모/손자녀 예로 설명했다. 의뢰서와 의사소견서의 역할을 설명하고, 동거·돌봄 조건과 공식 파일명을 보존했다. |
| 088 임신·출산 진료비 | judge 미달 | 다태아·본인부담금·차감과 지급 주체, 추가 지원 조건 및 지역 목록은 유지했다. 원문의 `비금여`를 그대로 소개해 어떤 비용인지 설명하지 못했다. |
| 090 에너지바우처 | judge 통과 | 소득 기준과 세대원 특성 기준의 AND, 특성 목록의 OR를 유지했다. 연탄전환 조건·소득인정액·기준 중위소득의 차이와 결제 방식을 설명했다. |

규칙 기반 사실 보존은 35/35, 절단·재시도·통신 실패는 0이다. 기계 스타일 통과는 0/3으로, 길이·잔존 표현 지적은 남았다. 이 숫자들을 독자의 이해율이나 모든 의미 관계의 보존율로 바꿔 읽지 않는다. 유료 레인은 088 judge 미달로 실패 종료했으며 이를 성공으로 숨기지 않았다.

원문의 `비금여`는 의미 확인이 필요한 입력이다. 이를 검사기에서 면제하거나 모델 지식으로 지원 범위를 확정해서 통과시키지 않았다. 확인된 원문 또는 검수된 용어 근거가 있어야 이 사례를 완성할 수 있다. 090의 ‘담당 시/군/구청 또는 해당없음’ 같은 원문 데이터 결함도 남겼다.
