# R3 평가 증거

2026-09-23 재결정(예약 기준 누적 US$40, 변형별 20, 반복 1회)에 따라 실행한 `baseline`/`r3` 두 변형의 실행 조건과 원문 transcript·passes JSON·gradle.log다. `manifest.json`은 파일별 SHA-256, `conditions.txt` 원문, 실행별 호출 수·토큰 합계·실제 비용·최대 예약액을 기록한다. `estimated_cost_usd`(예상 비용)는 확정 청구액이 아니다.

자료 출처·문서 ID·이용조건·고정 원문은 [R0 기준선](../2026-09-18-easy-read-r0-baseline.md)에 있다. `023` 원문은 제주특별자치도 공고 제2026-2658호이며 공공누리 제1유형 출처 표시 조건을 유지한다. 그 밖의 원문도 같은 기준선의 기관·서비스 식별자를 따른다.

`baseline/`·`r3/`은 개발 표본 6건(`070,087,023,072,077,088`) × 각 변형 1회의 완료된 실행(각 16호출)이다. `baseline-aborted/`는 2026-09-23 1차 승인(누적 US$15, 변형별 7.5) 아래 레인 예약이 다음 호출에서 변형별 cap을 넘어설 것으로 계산돼 023만 2회 돌고 선제 중단된 시도(6호출)이며, 비용 원장에만 포함하고 의미 검수 대상이 아니다. 판정·지연·토큰 수치와 예산 원장은 [평가 보고서](../2026-09-23-r3-model-evaluation.md)에 있다.

judge 호출의 원문(요청·응답)은 보존하지 않았다. `passes/*.json`은 `convert`·`repair` 호출만 기록하며, judge 판정 결과는 gradle.log의 집계 줄에서 가져온다(평가 보고서 §10 참고).

이 6건은 [R2 모델 평가](../2026-09-21-r2-model-evaluation.md) 프롬프트 튜닝에 이미 쓰인 **개발 표본**이며 별도로 고정된 보류 표본이 아니다. AC-R3 "BASELINE 대비 의미 오류 증가 없음" 판정에 쓸 독립 보류 표본은 아직 확보하지 않았다([평가 보고서 §9](../2026-09-23-r3-model-evaluation.md#9-남은-것)). 이 파일들을 승인된 golden 답안으로 편입하지 않는다.
