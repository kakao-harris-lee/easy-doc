# R2 행동 안내문 정성 의미 검수

검수일: 2026-09-21

대상: R2 실행에서 보존된 후보 20개. 최초 실행에서는 11개가 valid, 9개가 invalid였으나, 표기·문서명 처리만 좁혀 보완한 validator로 동일 응답을 다시 검사한 결과 20개 모두 production parser/validator를 통과했다. 최초 11/9 결과는 [R2 오탐 보완·파일럿·배포 확인 기록](2026-09-21-r2-release-verification.md)과 [R2 모델 평가 보고서](2026-09-21-r2-model-evaluation.md)에 역사적 실행 결과로 남긴다.

기준: `2313dc6af1079570fab2b3dc8d6c2b6eda134bc9`의 R0 고정 질문·원문

이 문서는 **독립적인 사람 파일럿이나 사용자 독해 실험이 아니다.** 고정된 R0 질문과 원문 source unit, 후보의 source anchor를 대조한 AI 정성 검수 기록이다. 따라서 이 결과만으로 production 의미 품질을 승인하지 않는다. 최초 parser가 invalid로 분류한 9개도 의미 오류 9개로 세지 않지만, validator 통과를 의미 정확성 승인으로 간주하지 않고 이 문서에서 별도로 정성 검수했다.

## 검수 방법

다음 20개 transcript를 읽고 R0의 자격·예외·금액·기한·행동 질문과 대조했다.

각 후보에서 다음을 확인했다.

- 지원 대상과 자격 조건이 원문과 같은지
- 금액·기간·기한·횟수·예외 조건이 빠지거나 바뀌지 않았는지
- 신청 장소·신청자·서류·후속 행동이 실제 원문에 있는지

`valid`는 JSON 구조·원문 anchor·제한된 사실 규칙 validator를 통과했다는 뜻이다. 아래의 “보존” 판정도 사람의 최종 의미 승인과 구분한다. 좁은 validator 보완은 `한명`/`한 명`, `10억`/`10억원`, 문장 안 파일명·서식 번호의 표기 대응만 다루며 후보의 의미를 새로 만들거나 보정하지 않았다.

## 공통 관찰

20개 후보에서 원문에 없는 전화번호, 서류, 신청기한, 기관명 또는 자격을 임의로 만들어 넣은 사례는 확인하지 못했다. `[[전화번호1]]`는 모두 확인 필요 상태로 남겼고, 074의 신청 마감일과 077의 신청 단계처럼 원문에 없는 정보는 `not_in_source` 또는 주의 문구로 처리했다. 추가로 읽은 9개에서는 070·023·089·097의 최초 거절이 의미 변경이 아닌 표기·문서명 처리 문제임을 확인했다.

R0 핵심 사실 보존은 기존 11개와 추가 9개에서 전반적으로 확인된다. 추가 9개 중 070 r1/r2, 023 r1, 089 r1/r2, 097 r1/r2에서는 Q1–Q6의 자격·금액·기한·행동을 바꾼 사례를 찾지 못했다. 088 r1/r2는 대상·금액·절차는 보존했지만 Q5의 `비금여 포함`을 함께 쓰지 않아 같은 의미 확인점이 반복됐다. 기존 101의 법령명·금액·25% 기준 연결, 089의 소득 범위 충돌, 097의 유형별 기준과 다자녀 순위 모호함은 `needs_review`로 유지한다.

이번 검수의 결론은 “validator 보완 후 같은 R2 응답 20개 모두를 AI 의미 검수 대상으로 삼았고, 원문 근거와 R0 핵심 사실은 대체로 보존되었지만 088 두 반복의 비급여 포함 범위와 기존·보류 문서의 명시적 확인점이 남았다”이다. 20/20 validator 통과는 사람 의미 승인이나 실무자 파일럿 완료가 아니며, production readiness 승인도 아니다. 최초 9개 invalid의 원인을 의미 오류로 판정하지 않고, 후보 검증 결과와 사람 의미 판정은 [R2 모델 평가 보고서](2026-09-21-r2-model-evaluation.md)의 호출·parser 결과 및 [오탐 보완·파일럿·배포 확인 기록](2026-09-21-r2-release-verification.md)과 별도로 유지한다.
