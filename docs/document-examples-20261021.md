# 공개 문서 예시와 첫 변환 시작

## 범위와 완료 기준

- 가정통신문, 고객 안내문, 제품 설명의 가상 원문 3종을 새로 작성한다. 원문·쉬운 표현·편집 제안을 가입 없이 볼 수 있게 한다.
- 설명용 예시는 실제 서비스 실행 결과나 사람의 검수 실적으로 표시하지 않는다. 고객 자료와 공개 사용 조건을 확인하지 못한 평가 자료는 재사용하지 않는다.
- 로그인 후 기존 변환 폼에 원문을 불러온다. 불러오기만으로 API 제출·크레딧 사용을 하지 않으며, 기존 입력이 있으면 교체 여부를 확인한다.
- 목록과 상세 3개 페이지를 프리렌더하고 고유 메타데이터·canonical·사이트맵·nginx 경로를 제공한다.
- 원문 TXT를 함께 제공한다. 실제 DOCX/HWPX 변환 결과 파일은 서비스 실행과 문서 편집기에서의 확인을 거친 후 별도 공개한다. 설명용 파일을 실제 변환 실적으로 만들지 않는다.

## 작업 경계

Codex가 설계·구현·검증·자체 리뷰를 담당한다. 수정 경로는 `frontend/`와 이 문서다. 인증, API, 결제, 크레딧 정책은 바꾸지 않는다. 유료 LLM을 실행하지 않는다. 수정·재검증은 최대 3회로 제한한다.

## 검증

`npm run check`, `npm run test -- --run --maxWorkers=2`, `npm run build`, nginx 설정 검사와 실제 HTTP 응답, 모바일·데스크톱 브라우저 확인을 실행한다. 기존 입력 보호, 자동 제출 방지, 실제 제출 경로, 공개 HTML의 내용과 색인 설정을 기존 Vitest 체계에서 검증한다.

## 자료 확보와 다음 단계

이번 원문과 설명용 재작성은 이 기능을 위해 AI로 새로 작성한 가상 자료다. 기관·고객·제품의 실제 사례가 아니다. 기존 golden corpus는 공개 권리와 개인정보 검토가 별도로 필요하므로 사용하지 않는다.

실제 사례는 작성자가 공개를 허락한 문서 또는 재사용 조건을 확인한 공개 자료를 확보하고, 출처·사용 조건·비식별 처리·검토자·검토일을 기록한 뒤 게시한다. 실제 서비스 실행 결과를 비교할 때는 입력, 모델/설정, 읽기 수준, 실행일, 수정 내역을 함께 보관한다. 유료 실행은 별도 예산 승인이 필요하다.

공개 자료 후보는 공공누리에서 찾되 개별 문서의 이용 조건을 확인한다. 제1유형은 출처를 표시하고 상업적 이용·변경이 가능한 자료의 출발점이다. 유형 안내는 [한국저작권위원회](https://www.copyright.or.kr/gov/nuri/guide/index.do)에서 2026-10-21 확인했다. 학교·기업 홈페이지에 공개되어 있다는 사실만으로 재작성·마케팅 게시를 허용한 것으로 보지 않는다.
