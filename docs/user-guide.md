# 이용 가이드 작성 규칙

공개 화면의 단일 원본은 `frontend/src/content/guide/user-guide.md`입니다. `GuidePage`가 이 파일을 그대로 읽어 표시하므로, 사용자에게 보이는 본문을 이 문서에 복사하지 않습니다.

## 작성 원칙

- **지금 실제로 되는 기능만** 적습니다. 계획 중인 기능을 사용 가능한 것처럼 안내하지 않습니다.
- 첫 화면에는 정의 문장, 초안 고지와 꼭 알아야 할 주의사항, 세 가지 사실(누구를 위해·무엇을 넣어·무엇이 나오는가), 무료 체험 시작 방법(휴대폰 인증 → 체험 크레딧), 사용 흐름 순으로 둡니다. 체험 절과 사용 흐름은 각각 3항목 번호 목록 하나로 쓰며, 가이드의 최상위 번호 목록은 이 두 카드 띠에만 씁니다(일반 나열은 글머리 기호).
- 플랜·크레딧 안내는 「플랜 이용하기」 절 하나에 모으고, 값은 `frontend/src/content/plans/targetPlans.ts`와 결제 화면 배지 문구를 그대로 옮긴 뒤 `GuidePage.test.tsx`에서 대조합니다. 소셜 로그인 인증 여부는 제공자 이름을 나열하지 않고 「제공자가 이메일을 확인해 넘겨주면 이 단계가 없다」는 구조로 적습니다.
- 문장은 짧게 쓰고, 화면에 보이는 메뉴와 버튼 이름을 그대로 사용합니다.
- 파일 형식, 크기, 보관 기간, 이용량처럼 바뀔 수 있는 값은 구현 및 계약과 함께 확인합니다.
- 화면 동작이 바뀌면 공개 원본과 관련 테스트를 같은 변경 단위에서 수정합니다.

## 운영 메모

**2026-09-12 의견 확인:** 의견 제출 후와 제출한 변환을 다시 열 때 입력 폼을 숨깁니다. 관리자는 계정 메뉴 **관리 → 사용자 의견**에서 제출 내용과 만족도·사용 의향·소요 시간을 최신순으로 조회합니다. 자유 의견은 기존 보존 기간을 따르며, 문서 원문과 변환 본문은 관리자 의견 응답에 포함하지 않습니다.
