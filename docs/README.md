## 자료 성격

- `plans/archive/python-era/`: 과거 Python 구현 계획. 현재 실행 금지.
- `plans/archive/transition/`: Kotlin 단일 런타임으로 전환한 결정 기록.
- `benchmarks/`, `quality/`: 당시 모델/품질 관찰 기록. 현재 Kotlin CI 통과 근거가 아니다.
- `golden/`, `golden-drafts/`: 원문과 수집 초안. 실행 코드가 아니다.

활성 문서의 명령은 Kotlin/Gradle, React/npm, Docker Compose만 사용한다.
