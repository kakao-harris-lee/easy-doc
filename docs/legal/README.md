# 법정 고지 문서

공개할 이용약관과 개인정보처리방침의 원본이다. 화면은 이 파일을 렌더링한다.

## 지금 상태 — **초안이다. 아직 공개하지 않는다**

두 문서 모두 **게시 전에 채워야 할 빈칸이 있다.** 빈칸은 본문에서 `⟨확인 필요: …⟩` 표기로 남겼다 — **하나라도 남아 있으면 게시하지 않는다.** 채우는 방법과 담당은 `docs/plans/2026-09-10-personal-data-inventory.md` §5에 있다.

법률 검토를 필수 관문으로 두지 않기로 했다(인벤토리 §5 머리말). 그 대신 **공개 법령·기관 지침과 실제 계약·설정·구현 증거를 대조해 직접 확정한다.** 그러니 이 문서의 정확성은 그 대조를 마쳤는지에 달려 있다.

## 버전 문자열

가입 동의 기록(`signup_consents.document_version`, 계획 `2026-09-10-signup-consent.md` §2 결정 4)이 **어느 판에 동의했는지**를 남겨야 한다. 그래서 두 문서는 머리에 **명시적 버전 문자열**을 갖는다.

- 형식은 `terms-YYYY-MM-DD` · `privacy-YYYY-MM-DD`다.
- 파일 내용의 해시가 아니라 **사람이 읽고 대조할 수 있는 문자열**이다.
- **문장을 고치면 버전을 올린다.** 오타 수정도 마찬가지다 — 「무엇에 동의받았는가」를 입증해야 하는 자리이므로 판을 흐리게 두지 않는다.
- 날짜는 **게시 예정일**이고, 게시 전 초안 상태에서는 `-draft` 접미사를 붙인다.

## 고칠 때

1. 본문을 고친다.
2. 버전 문자열을 올린다.
3. 실제 처리 흐름과 어긋나지 않는지 확인한다 — 스키마·파기 배치·공급자 설정이 근거다(인벤토리).
4. 이미 동의한 이용자에게 소급 적용하지 않는다. 재동의가 필요한 변경인지 판단은 별개 작업이다(`2026-09-10-signup-consent.md` §2 결정 6).
