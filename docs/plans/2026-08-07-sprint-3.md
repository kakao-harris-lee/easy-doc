# 스프린트 3 구현 계획 — 분할 화면 에디터 + docx 다운로드 + 변환 기록 (파일럿 데모 가능 상태)

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 파일럿 실무자가 브라우저에서 가입 → 문서 업로드 → 변환 → **분할 화면 검수(직접 수정) → docx 다운로드 → 변환 기록**까지 수행할 수 있는 데모 가능 상태 (master-plan 로드맵 단계 1, 스프린트 3 · Lean MVP 4.0).

**Architecture:** 백엔드는 기존 FastAPI에 검수 저장·내보내기 엔드포인트 추가(레이어 규칙 유지). 프론트는 `frontend/`에 React + TypeScript(Vite) 신설 — LLM 직접 호출 금지(CLAUDE.md), 모든 통신은 백엔드 API. AI 초안은 보존하고 담당자 수정본을 별도 컬럼에 저장(**수정률 KPI**(master-plan 7장) 측정 기반).

**범위 제외(Lean):** 문단 단위 재변환, pdf/hwp 내보내기, 크레딧 표시, 랜딩 페이지, 팀 계정. (P0 이후 단계)

**전제:** 골든셋 재평가(45건)는 미션 S로 선행 실행 중 — 결과는 기록만 하고 스프린트 진행을 막지 않는다(품질 이슈 발견 시 별도 보고).

## 미션 T — 백엔드 검수·내보내기

### Task 1: 검수 수정 저장

- **마이그레이션 0004**: `conversions`에 `edited_text_encrypted: bytes | None`, `reviewed_at: datetime | None` 추가. AI 초안(`easy_text_encrypted`)은 불변 보존 — 수정률 KPI(초안 대비 편집 비율)의 원천. 롤백 지원.
- `PUT /conversions/{id}` — body `{edited_text: str}`(1자 이상, 상한 = 원문 상한과 동일 정책). 소유자만(404), status=done인 변환만(그 외 409 `ConflictError` 신설 → errors.py 매핑). 암호화 저장 + `reviewed_at` 갱신. 응답은 갱신된 조회 스키마.
- `GET /conversions/{id}` 응답에 `edited_text`(있으면)·`reviewed_at` 추가 — 프론트는 `edited_text ?? easy_text`를 편집 초기값으로.
- 테스트: 소유자 격리·상태 가드·암호화 저장(원시 컬럼 평문 부재)·재수정 덮어쓰기.

### Task 2: docx/txt 내보내기

- `GET /conversions/{id}/export?format=docx|txt` — 소유자만, done만. 내용은 `edited_text ?? easy_text`(검수본 우선). **플레이스홀더 복원**: `masked_items`로 `[[전화번호1]]` → 원문 값 치환(내보내기는 담당자 최종 산출물 — 마스킹 해제가 목적. 복원은 이 엔드포인트에서만, 사유 주석).
- docx 생성: python-docx — 제목(문서 title) + 본문 문단(빈 줄 기준 분리), "쉬운 글 변환 초안 — 검수 완료 문서" 같은 꼬리말 금지(깨끗한 산출물). `Content-Disposition` 파일명은 RFC 5987 인코딩(한글 제목).
- txt: UTF-8 BOM 없이.
- 테스트: 복원 정확성(플레이스홀더 잔존 0), docx 파싱 왕복(python-docx로 재열기), 파일명 헤더, 소유자·상태 가드.

### Task 3: CORS + 마무리

- `app/main.py`에 CORSMiddleware — 허용 origin은 `Settings.cors_origins: list[str]`(기본 `["http://localhost:5173"]`), credentials 불필요(Bearer 헤더 방식). 사유 주석: 파일럿은 동일 호스트 nginx 서빙이 기본, dev만 cross-origin.
- 게이트 + DB 스위트 + 커밋 2~3개.

## 미션 U — 프론트 스캐폴드

- `frontend/`: Vite + React 18 + TypeScript(strict). 패키지 매니저 npm(잠금 파일 커밋).
- 품질 게이트: `tsc --noEmit`, ESLint(typescript-eslint 권장 + react-hooks), Prettier, Vitest(+Testing Library) 최소 구성. `frontend/package.json` scripts: `check`(tsc+lint), `test`, `build`.
- CI: 프론트 잡 추가(paths 필터 없이 단순하게 — node 20, `npm ci && npm run check && npm run test -- --run && npm run build`).
- API 클라이언트(`src/api/`): fetch 래퍼(BASE_URL env `VITE_API_BASE_URL` 기본 `http://localhost:8000`), 토큰 저장 localStorage(XSS 트레이드오프 주석 — 파일럿 수용, P0에서 재검토), 401 시 로그인 이동. 타입은 백엔드 Pydantic 스키마와 1:1 수동 정의.
- 화면: 로그인/가입(폼 검증·오류 표시), 인증 라우팅(react-router), 로그아웃.
- **KWCAG 기본 원칙**(전 미션 공통, 접근성 서비스로서 필수 — master-plan 6.3): 시맨틱 랜드마크, 모든 입력에 label, 키보드 조작 가능, 포커스 표시, 대비 4.5:1, lang="ko". 자동 검사는 eslint-plugin-jsx-a11y.
- 한국어 UI 문구·주석. "의무화" 표현 금지(화법 가이드).

## 미션 V — 핵심 UX

- **업로드 화면**: 텍스트 붙여넣기 textarea + 파일 선택(docx/pdf/hwpx, 10MB·4,000자 안내) → POST /documents → 폴링(GET /conversions/{id}, 2초 간격, pending/processing 진행 표시, failed 시 사유 안내 문구 매핑).
- **분할 화면 에디터**: 좌 원본(읽기 전용) / 우 결과 textarea(편집). 상단 고정 배너 **"AI가 만든 초안입니다 — 반드시 검토 후 사용하세요"**(HITL, master-plan 3.3). 마스킹 항목 패널: category·placeholder·original 표시(검수용 — 이 화면에서만), 결과 내 `[[…]]` 하이라이트. `missing_placeholders` 있으면 경고 배지.
- 저장(PUT) — 저장 성공/실패 피드백, 미저장 이탈 경고. docx/txt 다운로드 버튼(export 호출, blob 다운로드).
- **변환 기록**: GET /documents 목록(제목·상태·글자 수·생성일·검수 여부), 페이지네이션(has_more), 행 클릭 → 에디터 재진입, 재다운로드.
- 컴포넌트 테스트: 폴링 전이·에디터 초기값(edited 우선)·저장 흐름·다운로드 트리거(모킹) 최소 8건+.
