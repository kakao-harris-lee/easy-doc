# 가이드와 예시 화면 간소화

- 범위: `frontend/`의 가이드, 공개 예시, 홈의 예시 안내, 입력 폼의 예시 선택과 모바일 입력 방식 버튼. API·결제·문서 변환 기능은 유지한다.
- 기준: 첫 화면에는 사용 순서와 핵심 고지만 둔다. 추가 설명은 접고, 모바일에서는 원문/쉬운 글을 전환해 읽는다. 예시 불러오기도 기본으로 접는다.
- 보존: 개인정보·AI 초안 고지, 가상 예시 표시, 체험·요금 조건, 파일 형식과 제약, 보관 기간, 기존 입력 교체 확인, 검색용 전체 본문.
- 검증: 타입·린트·포맷, 전체 Vitest, 빌드, 프리렌더, 기존 E2E 및 320/390/1440px의 글 전환·접기·키보드·가로 넘침 확인. 가이드와 예시 목록의 초기 높이를 변경 전과 비교한다.
- Codex가 구현·검증·자체 리뷰한다. 수정·재검증은 최대 3회. 유료 LLM 호출은 없다.
