# 검색 노출과 체험 안내 개선

## 범위와 완료 기준

- 홈페이지: 쉬운 글 변환이라는 검색 의도, 무료 체험 조건, 원문 비교·문단 재변환·문서 출력의 사용 가치를 보여 준다.
- 공개 이용 가이드 `/guide`: 기존 Markdown을 사전 렌더링하고 고유 제목·설명·대표 주소와 사이트맵 항목을 제공한다. 인증·사용자 문서는 기존 noindex를 유지한다.
- 사업자 정보: 사용자가 확인한 신고번호를 기존 회사 정보 구성에 넣는다. 번호를 추정하지 않는다.
- 운영자 확인: 외부 접근, 구글·네이버 색인 확인, 검색 유입 측정 순서를 기록한다.
- 백엔드·결제 정책·요금·실제 LLM 호출은 변경 범위가 아니다.

## 검증과 리뷰

- `frontend`: `npm run check`, `npm run test -- --run`, `npm run build`.
- 기존 프리렌더 테스트에서 홈페이지·가이드의 본문, 대표 주소, 제목, 사이트맵과 셸의 noindex를 확인한다.
- 빌드 산출물을 nginx로 서빙하여 직접 요청·리다이렉트를 점검하고, 모바일 화면과 가입 링크를 브라우저로 확인한다.
- 최종 diff를 자체 리뷰한다. 수정 반복은 최대 3회이며, 외부 계정 권한이 필요한 색인 상태는 성공으로 간주하지 않는다.
- 기존 작업 트리의 미커밋 회사 정보와 원격에 없는 결제 UI 커밋을 보존한다. PR에는 이번 변경만 넣는다.

## 확인된 경계

- 10월 2일 등록·수집 요청 완료는 기존 작업 문서의 기록이며, 현재 색인 성공을 의미하지 않는다.
- 내부 DNS 접속은 성공하지만 공인 주소 접속과 외부 조회는 실패했다. 내부망의 공인 주소 재접속 제한과 실제 외부 장애는 구분되지 않았다.
- 경쟁 서비스와 실제 변환 품질을 비교하지 않았으므로 정확도 우위·의미 완전 보존·시간 절감 수치를 광고하지 않는다.
