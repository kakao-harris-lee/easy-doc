# 파일럿 참여 안내·동의·기록지 초안 (K3·K5)

작성일: 2026-09-23 · 상태: 초안. [사람 검증 착수 계획](2026-09-23-human-verification-kickoff.md) K3(R2 실무자 탐색 파일럿 참여자)·K5(게이트 ① 기관)의 2026-09-23 사용자 결정 「안내문·동의서·기록지 초안만 준비, 참여자·기관은 나중에 확정」에 따른 문서다. 참여자·기관·일시는 비어 있으며, 이름·연락처는 저장소에 기록하지 않는다. 정본은 [R2 파일럿 패킷](2026-09-21-r2-pilot-packet.md)과 [파일럿 실행서 「게이트 ① 판정」](../pilot-runbook.md#게이트--판정)이다.

## 1. 참여 요청 안내문 (V2 R2 실무자 탐색 파일럿용)

> 안녕하세요. 공공기관 안내문을 쉬운 글로 바꾸는 도구의 검수 화면을 개선하기 위해 실무자 분의 도움을 요청드립니다.
>
> - 무엇을 하나요: 공개된 복지 안내문 4건을 보시고, 안내문만 읽는 경우와 「행동 안내 초안」이 함께 있는 경우 각각에서 신청에 필요한 정보(대상·조건·서류·기한·제출처)를 찾아 답해 주십니다. 이어서 초안에서 잘못되거나 빠진 내용을 고쳐 주십니다.
> - 시간: 1인당 약 60~90분(추정, 패킷에 확정된 소요 시간 수치는 없음), 1회.
> - 개인 평가가 아닙니다: 개인의 업무 능력을 평가하지 않으며, 결과표에 이름·연락처를 넣지 않습니다. 언제든 중단할 수 있습니다.
> - 비용: 참여자에게 크레딧·비용을 부담시키지 않습니다. 실제 신청이나 결제는 하지 않습니다.
> - 기록: 문서별 답변·수정 내용과 활동 시간을 기록합니다. 녹음·화면 녹화는 기본적으로 하지 않습니다. 식별 가능한 기록은 세션 후 30일 이내 삭제합니다.
> - 문서: 공개 문서만 사용하며 실제 민원 문서·개인정보는 다루지 않습니다.
>
> 참여 가능하시면 가능한 날짜·시간대를 알려 주십시오.

## 2. 세션 시작 시 설명과 동의 확인

진행자가 읽는다(패킷 「진행자 안내와 과제 배치」 문구를 그대로 쓴다):

> 이 세션은 안내문과 검수 화면을 개선하기 위한 것입니다. 개인의 업무 능력을 평가하지 않습니다. 언제든 중단할 수 있습니다. 실제 신청이나 결제는 하지 않습니다. 시간과 문서별 답변·수정 내용을 기록하며 이름과 연락처는 결과표에 넣지 않습니다.

동의 기록(저장소 밖 보관):

| 항목 | 기록 |
|---|---|
| 참여자 코드 | P0_ (이름 대신 코드만) |
| 목적·측정 내용·중단 가능성 설명 받음 | 예 / 아니오 |
| 참여 동의 | 예 / 아니오 |
| 기록 보관·삭제 기한(30일) 안내 받음 | 예 / 아니오 |
| 일시·진행자 코드 | |

## 3. 세션 기록지 (문서 1건당 1행)

패킷 「세션 기록 양식」 그대로다. 탭 비활성·휴식·진행자 개입 시간은 제외하고, 읽기·정보 찾기와 수정 시간을 분리하며, 기록하지 못한 시간은 추정하지 않고 결측으로 둔다.

| 참여자 | 문서 / 조건(A 원문·B 초안) / 순서 | 활동 읽기·찾기 초 | 수정 초 | Q1~Q6 판정(통과·누락·의미 변경·원문 밖 추가·판정 불가) | 중대한 의미 오류와 근거 | 수정 필요 항목 / 전체 항목 | 도움 요청·접근성 관찰 |
|---|---|---|---|---|---|---|---|
| P01 | 070 A / 1 | | | | | | |
| P01 | 088 B / 2 | | | | | | |
| P01 | 074 A / 3 | | | | | | |
| P01 | 097 B / 4 | | | | | | |

과제 배치는 패킷의 P01~P05 표를 따른다. 세션 후 질문 세 가지: 「확인하기 어려웠던 조건」, 「빠진 정보」, 「수정에 가장 오래 걸린 부분」.

## 4. 게이트 ① 기관 안내 (V5용)

기관 담당자에게 보내는 요청 요지:

> 실제 업무 문서 10건(기관 합산, 가급적 실무자 2인 이상)을 도구로 처리해 보시고, 문서마다 검수 화면 하단의 피드백 폼(배포 의향·품질 만족도 1~5·소요 시간(분)·자유 의견)을 한 번 제출해 주시면 됩니다. 개인정보가 든 문서는 올리지 말아 주십시오. 착수 전에 지금 방식으로 문서 1건을 쉬운 글로 만드는 데 드는 시간을 알려 주십시오.

기존 방식 소요 인터뷰 기록(실행서 「기존 방식 소요」 표에 옮긴다):

| 기관 코드 | 문서 종류 | 기존 방식(외주·내부 작성 등) | 1건 소요 | 출처·일자 |
|---|---|---|---|---|
| | | | | |

착수 조건은 실행서 「사전 조건」을 따른다: 실제 provider와 유료 호출 승인, 개인정보 문서 지양 안내, 기존 방식 소요 인터뷰, 게이트 ⓪ 충족(2026-09-03 판정 완료). 통과 기준은 2026-09-04 확정값(배포 의향 8/10 이상, 만족도 평균 3.5 이상, 소요 시간 중앙값은 사람이 판정)이다.

## 5. 이 문서가 아닌 것

참여자 모집·기관 접촉·유료 호출의 승인이 아니다. 참여자·기관이 정해지면 착수 계획 §4의 K3·K5 행에 날짜와 함께 기록하고, 이 초안의 빈칸은 저장소 밖 기록지에서 채운다.
