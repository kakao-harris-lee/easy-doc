# R2 제한 파일럿 실행 패킷

작성일: 2026-09-21. 상태: 실행 준비, 참여자·일정 미확정. 실제 사람 평가 결과가 아니다.

## 범위와 착수 조건

실무자 3~5명이 공개 문서의 행동 안내 후보를 검수하고 신청 준비에 필요한 정보를 찾는다. 자동 테스트와 AI 의미 검수는 사람 평가를 대체하지 않는다. 신규 모델 생성 없이 [보존된 후보](../reports/2026-09-21-r2-model-evaluation-artifacts/README.md)로 검수 과제를 먼저 진행할 수 있다. 실제 제품 생성 흐름의 파일럿은 별도 환경의 버전·토글·예약 정산 확인 후 시작한다.

사용 문서는 [R0 기준선](../reports/2026-09-18-easy-read-r0-baseline.md)의 공개 표본으로 제한한다. 실제 민원 문서·개인정보는 이번 준비 패킷에 포함하지 않는다. 외부 제공 전 원 게시물의 이용조건과 출처 표시를 확인한다. 보류 표본을 본 이후의 추가 생성 품질 주장은 새 독립 표본으로 평가한다.

| 운영 항목 | 기록 |
|---|---|
| 기관 / 실무자 P01~P05 | 미정. 이름·연락처는 저장소에 기록하지 않음 |
| 진행 일시 / 진행자 / 판정자 | 미정 |
| 환경 URL / 실행 커밋 / API·worker 토글 | 배포 확인 후 기록 |
| 참여 조건 / 크레딧 부담 | 착수 전 확정. 동의 없이 참여자에게 비용을 부담시키지 않음 |
| 동의 / 열람 권한 | 목적·측정 내용·중단 가능성을 설명하고 동의 여부만 기록 |
| 기록 보관 / 삭제 | 제안: 담당자만 접근, 세션 후 30일 이내 식별 가능한 기록 삭제. 착수 전 담당자·날짜 확정 |
| 중단·복구 담당 / 24시간 관측 담당 | 착수 전 지정 |

## 진행자 안내와 과제 배치

“이 세션은 안내문과 검수 화면을 개선하기 위한 것입니다. 개인의 업무 능력을 평가하지 않습니다. 언제든 중단할 수 있습니다. 실제 신청이나 결제는 하지 않습니다. 시간과 문서별 답변·수정 내용을 기록하며 이름과 연락처는 결과표에 넣지 않습니다.”라고 설명하고 참여 동의를 확인한다. 녹음·화면 녹화는 기본적으로 하지 않는다.

각 참여자는 같은 문서를 두 번 보지 않는다. A는 원문, B는 원문 대조가 가능한 행동 안내 후보다. 두 조건 모두 동일한 원문 열람 권한을 주고, 안내 후보 열람 여부만 다르게 한다. 문서별 R0 Q1~Q6을 정답 없이 제시하고 원문 근거를 포함한 답변을 받는다. 이후 B에서 잘못되거나 빠진 내용을 수정하게 한다. 반복 후보는 run1로 고정하며 결과를 보고 유리한 반복을 고르지 않는다.

| 참여자 | 순서 1 | 순서 2 | 순서 3 | 순서 4 |
|---|---|---|---|---|
| P01 | 070 A | 088 B | 074 A | 097 B |
| P02 | 088 A | 070 B | 097 A | 074 B |
| P03 | 074 B | 097 A | 070 A | 088 B |
| P04 (참여 시) | 097 B | 074 A | 088 A | 070 B |
| P05 (참여 시) | 070 B | 088 A | 074 B | 097 A |

소표본에서 문서 난이도와 개인 차이를 완전히 제거할 수 없으므로 인과 효과를 주장하지 않는다. 101의 법령명·금액 조건 연결은 시간 비교와 별도로 모든 참여자가 검토할 수 있는 심층 확인 과제로 둔다. 추가 생성이나 정답 수정 없이 기존 후보·원문을 사용한다.

진행자 사전 메모: 088 후보 두 반복에서 비급여 포함 범위가 빠진 사실이 AI 검수로 확인됐다. R0 Q5에서는 누락으로 판정하며, 해당 후보를 출시 합격 사례로 제시하지 않는다. 참여자 응답 전에 정답을 알려주지 않고 과제 후 보완 필요 사항을 설명한다.

## 세션 기록 양식

아래 한 행을 문서마다 복사한다. 탭 비활성·휴식·진행자 개입 시간은 제외하며, 읽기·정보 찾기와 수정 시간을 분리한다. 기록하지 못한 시간은 추정하지 않고 결측으로 둔다.

| 참여자 | 문서 / 조건 / 순서 | 활동 읽기·찾기 초 | 수정 초 | Q1~Q6 각 판정 | 중대한 의미 오류와 근거 | 수정 필요 항목 / 전체 항목 | 도움 요청·접근성 관찰 |
|---|---|---|---|---|---|---|---|
| 미실행 | — | — | — | — | — | — | — |

질문 판정은 통과 / 누락 / 의미 변경 / 원문 밖 추가 / 판정 불가다. 정답은 R0 질문표에서 확인한다. 원문 자체가 불명확한 사항은 정답률 분모에서 제외하고 제외 사유를 남긴다. 원문과 반대되는 자격·제외·금액·기한·행동은 중대한 의미 오류로 기록한다. 문체 선호와 분리한다.

키보드만으로 원문 대조·후보 선택·수정·저장이 가능한지, 초점 이동이 예측 가능한지, 검수 필요 표시와 오류를 이해했는지 관찰한다. 세션 후 “확인하기 어려웠던 조건”, “빠진 정보”, “수정에 가장 오래 걸린 부분”을 묻는다.

## 판정과 중단

문서·조건별 표본 수, 정보 찾기 통과 수/평가 가능 질문 수, 활동 시간 중앙값, 수정 필요 항목 비율을 보고한다. 시간 단축률은 `(A 중앙값 - B 중앙값) / A 중앙값`이며 A가 0이거나 결측이면 계산하지 않는다. 탐색 목표는 중앙값 20% 단축과 정보 찾기 성공률 유지·향상이다. 참여자별 순위나 능력 평가는 하지 않는다.

자격·예외·금액·행동·기한의 중대한 의미 변경, 타인 데이터 노출, 중복 과금, 수정본 유실, 삭제 후 본문 노출이 확인되면 해당 흐름을 즉시 중단하고 증거와 영향 범위를 기록한다. 출시 판정은 실측 결과와 제품·배포 검증을 함께 보고 별도로 남긴다. 준비 완료나 자동 검증 통과를 파일럿 완료로 기록하지 않는다.

## 제품 경로 확인과 후속 관측

제품 경로 확인 시 환경·커밋·schema·토글, 정상/실패 요청 식별자, 예약·소비·반환 금액을 개인정보 없이 기록한다. 크레딧은 100자 단위 올림 × 0.1이며 실제 생성은 호출 시작 최대 3회 정책을 적용한다. 공개 환경 전체에 토글을 켜는 방식으로 제한 참여를 대체하지 않는다.

추가 유료 모델 호출은 평가 누적 US$50에 합산한다. 기존 20회 예상 비용 US$2.880730, 보수적 예약 US$10.185420을 유지하며 남은 예약 가능액은 US$39.814580이다. 이 문서는 추가 호출을 실행한 기록이 아니다.

담당자가 배포 후 1시간·24시간에 오류/충돌, 남은 예약, 작업 상태, 추가 비용, 삭제 상태를 확인하고 기록한다. 현재 예약된 관측이나 자동 모니터는 없다.
