# Kotlin 이 포팅을 끝냈다고 **선언**하는 parity 도메인 목록.
#
# ── 이 파일이 있는 이유 ────────────────────────────────────────────────────
# parity 게이트는 도메인 11개(정본: dump_parity_fixtures.py 의 BUILDERS 키)를 전부
# 요구한다. 그런데 Kotlin 포팅은 Phase 2(도메인 8개)에서 도메인을 나눠 진행한다.
#
# ── 2026-08-12 2차 개정 주의: crypto·jwt·argon2 는 이제 parity 대상이 아니다 ──
# 재개발 전환으로 값 동일성(양방향/compat) 요구가 소멸했다(계획 §4.3 2차). 저장 암호화
# (crypto) 정확성은 parity 가 아니라 Kotlin 자체 테스트 + migration-safety-gate I-7 이
# 판정하고, jwt·argon2 는 I-9·I-8 + 필수조치 A·B 회귀가 판정한다. 그래서 이 세 도메인은
# 이 파일에 선언하지 않는다(선언하면 없는 parity 비교를 요구하게 된다). 이 셋이
# dump_parity_fixtures.py 정본·.github/parity-canonical-floor.txt(정본 11)에 남아 있는
# 문제는 이 파일 밖(python-kotlin-parity 스킬 소유)이며 별도 조정 대상이다. 그래서 전환 기간 내내 "fixture 는 있는데
# Kotlin 구현이 아직 없는 도메인"이 존재한다.
#
# 그 상태를 다루는 방법은 둘뿐이다.
#   (a) 게이트를 느슨하게 만든다 — 없으면 건너뛰고 통과시킨다.
#   (b) **무엇을 검증하지 않는지 선언하게 하고, 그 선언을 실행과 대조한다.**
# (a) 는 "검증하지 않은 것"이 "통과"로 집계되는 길이고, 이 하네스가 존재하는 이유가
# 정확히 그 실패를 막는 것이다. 그래서 (b) 를 택했다. 이 파일이 그 선언이다.
#
# ── 이 파일이 지켜지는 방법 ────────────────────────────────────────────────
# 손으로 적는 선언은 그 자체로는 아무것도 보장하지 않는다. 두 방향에서 실행과
# 대조되기 때문에 의미를 갖는다 (`./gradlew parityManifestCheck`).
#
#   선언 O / 산출 X → 빌드 실패. "포팅했다"고 적어 놓고 산출물이 없는 상태다.
#                     여기서 막지 않으면 미검증이 통과로 집계된다.
#   선언 X / 산출 O → 빌드 실패. 선언하지 않은 도메인은 CI 비교에서 빠지므로,
#                     산출물만 만들고 선언을 빼면 값 비교를 조용히 건너뛸 수 있다.
#
# 즉 이 파일에서 도메인을 **지우면** 해당 도메인의 Kotlin parity 테스트까지 함께
# 지워야 빌드가 산다. 한 줄 지우기로 게이트를 무르게 만들 수 없다는 뜻이다.
#
# ── 적는 방법 ──────────────────────────────────────────────────────────────
# 한 줄에 도메인 하나. `#` 뒤는 주석. 도메인 이름은 `parity/fixtures/` 의 디렉터리
# 이름과 같아야 하고, 정본에 없는 이름을 적으면 CI 가 막는다.
# 가능한 값(정본 확인: `uv run python .claude/skills/python-kotlin-parity/scripts/dump_parity_fixtures.py --list`):
#   masking  text  style  style-tables  prompts  postprocess  repair-adoption  export   ← Phase 2
#   jwt  argon2                                                                        ← (옛 Phase 3) 2026-08-12 2차: parity 아님 → migration-safety-gate I-9·I-8. 선언 금지
#   crypto                                                                             ← (옛 Phase 4) 2026-08-12 2차: parity 아님 → Kotlin 자체 테스트 + I-7. 선언 금지
#
# ── 현재 상태: Phase 2 진행 중 — 선언 7개 ──────────────────────────────────
# Phase 1 은 골격만 만들었고 선언이 0개였다(= 게이트 미가동). Phase 2 에서 모듈을 하나
# 끝낼 때마다 여기에 한 줄씩 **추가**한다. 아직 선언하지 않은 도메인
# (text·style·style-tables·prompts·postprocess·export)은 값 비교를 받지 않는다 —
# CI 가 그 목록을 "아직 검증하지 않은 도메인"으로 매 실행 경고한다.

masking          # 2026-08-13 · 생산자 core/src/test/.../privacy/MaskingParityTest.kt
repair-adoption  # 2026-08-13 · 생산자 application/src/test/.../conversion/ConversionParityTest.kt
# 아래 다섯은 2026-08-14 · 생산자 core/src/test/kotlin/kr/easydoc/core/CoreDomainsParityTest.kt
text             # 제어문자 제거
style            # 문장 분리 + 길이·쉼표 규칙
style-tables     # 정책 상수와 큐레이션 표
prompts          # 시스템·사용자·보정 프롬프트
postprocess      # 껍데기 제거
export           # 파일명 정제 · RFC 5987 · TXT 바이트
