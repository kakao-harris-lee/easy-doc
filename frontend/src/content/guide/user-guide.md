# 이용 가이드

![어려운 문서가 짧고 읽기 쉬운 문서로 바뀌는 모습](/landing-document-flow.svg)

행정·복지·법률 안내문을 발달장애인 등 정보를 이해하기 어려운 사람이 읽을 수 있는 쉬운 글 초안으로 바꿉니다. 마무리는 담당자가 합니다.

> **꼭 확인해 주세요.** 결과는 초안입니다. 날짜·금액·대상·조건을 원문과 비교해 담당자가 확인한 뒤 배포하세요. 개인정보가 담긴 문서는 올리지 마세요.

---

## 이 서비스는

- **누구를 위해** — 발달장애인·고령자 등 어려운 글을 읽기 힘든 사람
- **무엇을 넣나** — 외부에 배포하는 안내문·설명문·신청 안내·공지문
- **무엇이 나오나** — 담당자가 확인하고 고쳐서 마무리하는 **초안**

---

## 무료로 먼저 써 보세요

가입하고 휴대폰 인증만 하면 **체험 5크레딧**을 드립니다. 카드 등록 없이 **약 5,000자**(안내문 두세 장)를 바로 바꿔 볼 수 있습니다.

1. **가입·로그인** — 이메일 또는 구글·카카오·네이버 계정으로 가입합니다.
2. **휴대폰 인증** — 010 번호로 인증번호를 받아 입력합니다.
3. **5크레딧 받기** — 바로 변환을 시작합니다.

- 이메일·네이버 가입자는 메일로 받은 인증 코드(10분 유효)를 먼저 입력해야 합니다. 구글·카카오 계정은 이 단계가 없습니다.
- 번호 하나에 한 번만 드리며, 받은 뒤 **한 달 안에** 쓰면 됩니다.

---

## 세 단계로 이용하세요

1. **원문 넣기** — 글을 붙여넣거나 파일을 올립니다.
2. **쉬운 글 만들기** — 변환이 끝날 때까지 기다립니다. 다른 화면으로 이동해도 변환은 계속됩니다.
3. **확인하고 내려받기** — 원문과 결과를 비교하고, 필요한 곳을 고친 뒤 저장합니다.

---

## 원문 준비하기

- **맞는 문서** — 복지 서비스 신청 안내 · 공지문 · 지원금·제도 안내
- **넣지 않는 문서** — 개인정보가 든 민원 서류 · 외부에 공개하지 않는 내부 문서

원문에 있는 내용만 쉬운 글로 바꾸는 것이 목표입니다.

### 글 붙여넣기를 권장합니다

파일 구조의 영향을 받지 않아 가장 안정적입니다. 파일이 필요하면 아래 형식을 올릴 수 있습니다.

| 올릴 파일        | 알아둘 점                                                             |
| ---------------- | --------------------------------------------------------------------- |
| `.docx`, `.hwpx` | 원본 서식을 최대한 유지하지만 줄바꿈·표·쪽 배치는 달라질 수 있습니다. |
| `.pdf`           | 읽는 순서나 표 구성에 따라 글이 빠지거나 섞일 수 있습니다.            |
| `.txt`           | 서식 없는 일반 텍스트입니다.                                          |

구버전 `.doc`, `.hwp`는 각각 `.docx`, `.hwpx`로 다시 저장해 주세요.

- 파일은 **10MB 이하**여야 합니다.
- 글은 공백을 포함해 **한 번에 20,000자까지** 바꿀 수 있습니다. 긴 문서는 장·절 단위로 나누면 결과가 더 자연스럽습니다.

### 개인정보는 먼저 지워 주세요

주민등록번호나 카드번호처럼 일정한 형태의 값은 화면에서 경고하지만, 이름·주소까지 모두 찾아내지는 못합니다. 경고가 뜨면 개인정보를 지우고 다시 올려 주세요. 개인정보가 아닌 접수번호라면 **「이대로 진행」 버튼**을 누를 수 있으며, 이때 값은 가려지지 않고 그대로 전송됩니다.

## 결과 확인하고 내려받기

검수 화면에서 원문과 쉬운 글을 비교합니다. 좁은 화면에서는 **원문과 결과가** 탭이나 위아래 영역으로 나뉩니다.

- **직접 고치기** — 결과를 편집하고 저장합니다.
- **문단 다시 변환하기** — 아쉬운 문단만 다시 바꿉니다. 남은 횟수는 화면에서 확인할 수 있습니다.
- **쉬운 말 찾기** — 어려운 낱말을 선택해 쉬운 대체어를 찾습니다.

| 원본                | 내려받기         |
| ------------------- | ---------------- |
| 붙여넣은 글, `.txt` | `.txt`           |
| `.docx`, `.hwpx`    | 올린 형식과 같음 |
| `.pdf`              | `.txt`           |

PDF는 검수한 글만 TXT로 내려받습니다. 원본 레이아웃과 스타일은 유지되지 않습니다. DOCX·HWPX도 문장 길이에 따라 원본 배치가 달라질 수 있으니 받은 파일을 한 번 더 확인해 주세요.

---

## 플랜 이용하기

체험 크레딧을 다 쓰면 **플랜과 사용량** 화면에서 플랜을 고르세요.

| 플랜  | 월 크레딧 | 월 요금   | 결제                              |
| ----- | --------- | --------- | --------------------------------- |
| Start | 50        | 99,000원  | 테스트 결제 가능 · 실제 청구 없음 |
| Basic | 200       | 190,000원 | 결제 준비 중                      |
| Pro   | 1,000     | 599,000원 | 결제 준비 중                      |

- 크레딧은 **공백 포함 원문 100자마다 0.1크레딧**(올림)이며, 「더 쉽게」 단계는 **최소 1.2배**입니다. 문단을 다시 변환한 분량도 대상 원문만큼 포함되며, 남은 이용량(크레딧)은 **플랜과 사용량** 화면에서 확인합니다.
- 남은 크레딧은 다음 달로 넘어가지 않습니다. 크레딧이 없거나 결제가 만료·실패하면 새 변환을 시작할 수 없습니다.

## 작업 공간과 보관 기간

- **작업 공간**은 문서 목록과 사용량을 사업이나 부서별로 나누는 곳입니다. 문서가 보이지 않으면 현재 작업 공간을 확인해 주세요.
- **변환 기록**에서 지난 문서를 다시 열거나 삭제할 수 있습니다.
- 문서와 변환 결과는 올린 뒤 **30일이 지나면 자동으로 삭제**됩니다. 필요한 파일은 미리 내려받으세요.

---

## 자주 묻는 질문

### 인증 메일이 오지 않아요

스팸함을 확인해 주세요. 코드를 여러 번 요청했다면 1분 뒤 다시 받을 수 있습니다. 구글·카카오 가입자는 별도 인증이 없어 메일이 오지 않습니다.

### 체험 크레딧을 다 썼어요

**플랜과 사용량** 화면에서 Start 플랜을 테스트 결제로 등록하면 한 달 **50크레딧**이 적용됩니다. 실제 돈은 청구되지 않습니다.

### 결과가 마음에 들지 않아요

전체를 다시 변환하기보다 해당 문단의 **다시 변환**을 먼저 사용해 보세요. 후보를 확인한 뒤 직접 고칠 수도 있습니다.

### 예전에 만든 문서가 보이지 않아요

현재 작업 공간이 맞는지 확인하세요. 올린 지 30일이 지난 문서는 자동으로 삭제됩니다.

### 계정을 탈퇴하고 싶어요

**계정 설정**에서 탈퇴할 수 있습니다. 계정과 문서가 즉시 삭제되며 되돌릴 수 없습니다.
