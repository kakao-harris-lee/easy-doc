# 이용 가이드

글을 넣고, 쉽게 바꾸고, 확인해 저장하세요.

1. **원문 넣기** — 글 붙여넣기 또는 파일 올리기
2. **쉬운 글로 바꾸기** — 읽기 수준을 고르고 변환
3. **확인·저장** — 원문과 비교해 고친 뒤 다운로드

> AI 결과는 초안입니다. 날짜·금액·조건을 확인하세요. 개인정보·비공개 문서는 올리지 마세요.

## 무료 체험

**가입·휴대폰 인증 후 5크레딧**을 받습니다. 카드 등록 없이 기본 수준 약 5,000자를 변환할 수 있습니다.

- 010 번호당 1회 지급 · 지급일부터 한 달간 사용
- 이메일 인증이 필요한 계정은 먼저 인증합니다. 코드는 10분간 유효합니다.
- 문서가 없다면 **예시 불러오기**를 이용하세요. 불러오기는 무료, 변환은 크레딧을 사용합니다.

## 파일 형식과 다운로드

- **DOCX·HWPX → 같은 형식**으로 다운로드
- **붙여넣은 글·TXT·PDF → TXT**로 다운로드
- 파일 **10MB 이하** · 한 번에 공백 포함 **20,000자까지**
- 구형 HWP·DOC는 HWPX·DOCX로 저장해 올리세요.

DOCX·HWPX의 줄바꿈·표·쪽 배치는 달라질 수 있습니다. PDF는 글이 빠지거나 순서가 섞일 수 있고, 원본 서식은 보존되지 않습니다. 받은 파일을 확인하세요.

## 읽기 수준

- **레벨 1** — 중등
- **레벨 2** — 초등 5~6학년 · 기본 선택
- **레벨 3** — 초등 3~4학년 · 제공되는 환경에서 선택

레벨 1·2는 기본 크레딧, 레벨 3은 최소 1.2배를 사용합니다.

## 결과 확인과 수정

- 원문과 비교해 직접 고치고 저장하세요.
- 아쉬운 문단은 **다시 변환**할 수 있습니다. 남은 횟수는 화면에 표시됩니다.
- 어려운 낱말을 선택하면 쉬운 대체어를 찾을 수 있습니다.

개인정보 경고가 나오면 해당 정보를 지우세요. 이름·주소 등은 탐지하지 못할 수 있습니다. **이대로 진행**을 누르면 값이 가려지지 않고 전송됩니다.
