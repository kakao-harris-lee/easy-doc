# 이용 가이드

![어려운 문서가 짧고 읽기 쉬운 문서로 바뀌는 모습](/landing-document-flow.svg)

공공·복지 안내문을 쉬운 글 초안으로 바꾸고, 직접 확인해 문서로 내려받을 수 있습니다.

> **꼭 확인해 주세요.** AI가 만든 초안이므로 날짜·금액·대상·조건이 원문과 같은지 담당자가 검수해야 합니다. 개인정보가 담긴 문서는 올리지 마세요.

---

## 세 단계로 이용하세요

1. **원문 넣기** — 글을 붙여넣거나 파일을 올립니다.
2. **쉬운 글 만들기** — 변환이 끝날 때까지 기다립니다. 다른 화면으로 이동해도 변환은 계속됩니다.
3. **확인하고 내려받기** — 원문과 결과를 비교하고, 필요한 곳을 고친 뒤 저장합니다.

---

## 1. 원문 준비하기

### 글 붙여넣기를 권장합니다

파일 구조의 영향을 받지 않아 가장 안정적입니다. 파일이 필요하면 아래 형식을 올릴 수 있습니다.

| 올릴 파일        | 알아둘 점                                                             |
| ---------------- | --------------------------------------------------------------------- |
| `.docx`, `.hwpx` | 원본 서식을 최대한 유지하지만 줄바꿈·표·쪽 배치는 달라질 수 있습니다. |
| `.pdf`           | 읽는 순서나 표 구성에 따라 글이 빠지거나 섞일 수 있습니다.            |
| `.txt`           | 서식 없는 일반 텍스트입니다.                                          |

구버전 `.doc`, `.hwp`는 각각 `.docx`, `.hwpx`로 다시 저장해 주세요.

- 파일은 **10MB 이하**여야 합니다.
- 글은 공백을 포함해 **한 번에 20,000자까지** 바꿀 수 있습니다.
- 긴 문서는 장이나 절 단위로 나누면 결과가 더 자연스럽습니다.

### 개인정보는 먼저 지워 주세요

주민등록번호나 카드번호처럼 일정한 형태의 값은 화면에서 경고할 수 있지만, 이름·주소 등 모든 개인정보를 찾아내지는 못합니다.

경고가 뜨면 개인정보를 지우고 다시 올려 주세요. 개인정보가 아닌 접수번호라면 **「이대로 진행」 버튼**을 누를 수 있으며, 이때 값은 가려지지 않고 그대로 전송됩니다.

## 2. 가입하고 변환하기

이메일·비밀번호 또는 구글·카카오·네이버 계정으로 가입할 수 있습니다.

- 이메일 가입자는 메일로 받은 인증 코드를 입력해야 변환할 수 있습니다. 코드는 **10분간** 유효하며, 다시 받으려면 **1분**을 기다려야 합니다.
- 소셜 계정은 제공자가 이메일을 확인한 경우 별도 인증 코드 없이 바로 이용할 수 있습니다.
- 무료 체험은 **가입 → 로그인 → 휴대폰 인증번호 요청·확인 → 체험 5크레딧 발급** 순서로 시작합니다. 이메일 가입자는 휴대폰 인증 전에 이메일 인증을 먼저 완료해야 합니다.
- 국내 `010` 휴대폰 번호를 처음 인증하면 샘플 변환용 **5크레딧을 한 번** 지급합니다. 같은 번호로 다시 가입해도 중복 지급되지 않습니다.
- 체험 크레딧을 다 쓴 뒤에도 사용량 화면에서 **Start 테스트 결제**를 완료하면 한 달 **50크레딧**이 적용되며 실제 돈은 청구되지 않습니다.

원문을 올리면 변환이 시작됩니다. 진행 중에 다른 화면으로 이동해도 되며, 결과는 **변환 기록**에서 다시 열 수 있습니다.

---

## 3. 결과 확인하고 내려받기

검수 화면에서 원문과 쉬운 글을 비교할 수 있습니다. 좁은 화면에서는 원문과 결과가 탭이나 위아래 영역으로 표시됩니다.

- **직접 고치기** — 결과를 편집하고 저장합니다.
- **문단 다시 변환하기** — 아쉬운 문단만 다시 바꿉니다. 남은 횟수는 화면에서 확인할 수 있습니다.
- **쉬운 말 찾기** — 어려운 낱말을 선택해 쉬운 대체어를 찾습니다.

내려받기 형식은 원본에 따라 달라집니다.

| 원본                | 내려받기         |
| ------------------- | ---------------- |
| 붙여넣은 글, `.txt` | `.txt`           |
| `.docx`, `.hwpx`    | 올린 형식과 같음 |
| `.pdf`              | `.txt`           |

PDF 파일은 읽은 뒤 검수한 내용만 TXT로 내려받습니다. 원본 PDF의 레이아웃과 스타일은 유지되지 않습니다. DOCX·HWPX도 문장 길이에 따라 원본 배치가 달라질 수 있으니 받은 파일을 한 번 더 확인해 주세요.

## 작업 공간·기록·사용량

- **작업 공간**은 문서 목록과 사용량을 사업이나 부서별로 나누는 곳입니다. 문서가 보이지 않으면 현재 작업 공간을 확인해 주세요.
- 문서와 변환 결과는 올린 뒤 **30일이 지나면 자동으로 삭제**됩니다. 필요한 파일은 미리 내려받으세요.
- **1크레딧은 공백 포함 원문 1,000자**입니다. 최초 변환과 다시 변환에 사용한 양은 사용량 화면에서 확인할 수 있습니다.
- 이용량이 없거나 결제가 만료·실패한 상태에서는 새 변환을 시작할 수 없습니다.

## 자주 묻는 질문

### 인증 메일이 오지 않아요

스팸함을 확인해 주세요. 인증 코드를 여러 번 요청했다면 1분 뒤 다시 시도하세요. 소셜 가입자는 별도 인증이 필요 없어 메일이 오지 않을 수 있습니다.

### 결과가 마음에 들지 않아요

전체를 다시 변환하기보다 해당 문단의 **다시 변환**을 먼저 사용해 보세요. 후보를 확인한 뒤 직접 고칠 수도 있습니다.

### 예전에 만든 문서가 보이지 않아요

현재 작업 공간이 맞는지 확인하세요. 올린 지 30일이 지난 문서는 자동으로 삭제됩니다.

### 계정을 탈퇴하고 싶어요

**계정 설정**에서 탈퇴할 수 있습니다. 계정과 문서가 즉시 삭제되며 되돌릴 수 없습니다.
